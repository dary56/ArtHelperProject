# ArtHelper
Код веб-ориентированной информационной подсистемы для автоматизации процесса оформления научных публикаций в соответствии с требованиями журналов

Данная система помогает минимизировать количество технических ошибок при подготовке материала к публикации и сэкономить время авторов.

Применяются экстрактивные методы суммаризации (LSA/Sumy) для генерации аннотаций, статистического и графового анализа (YAKE) для извлечения ключевых слов, а также нейросетевых подходов машинного перевода (NMT) для получения англоязычных метаданных. В архитектуру системы интегрирован принцип «human-in-the-loop», обеспечивающий оптимальный баланс между автоматизацией технических операций и сохранением контроля автора над конечным результатом.

Используются библиотеки Python для обработки естественного языка (pypandoc, python-docx, beautifulsoup4, YAKE, Sumy, deep-translator, Pillow, docx2pdf), фреймворк Django и СУБД PostgreSQL. На клиенте применяется CKEditor 5 с математическим модулем для WYSIWYG-редактирования текста статьи.

Подсистема реализует следующий ключевой функционал: импорт и автоматическое структурирование черновиков .docx с применением шаблонов выбранного журнала; интеллектуальная поддержка заполнения метаданных, включающая автоматическую генерацию аннотаций и ключевых слов на основе содержания статьи, а также машинный перевод на английский язык; добавление библиографических источников по DOI через интеграцию с Crossref API с автоматическим формированием записей по ГОСТ Р 7.0.5-2008; визуальное редактирование текста с поддержкой таблиц и изображений; экспорт готовых документов в форматы .docx и .pdf с учетом издательских требований конкретного журнала.
